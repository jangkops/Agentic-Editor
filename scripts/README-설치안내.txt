========================================================
  Mogam Works 설치 안내 (macOS)
========================================================

이 폴더에는 다음 파일이 있습니다:
  • Mogam Works-0.3.0-arm64.dmg   → Apple Silicon(M1~M4) Mac 용
  • Mogam Works-0.3.0-x64.dmg     → Intel Mac 용
  • install-mac.command            → 설치 도우미 (권장)

내 Mac이 어느 것인지 모르면: 화면 왼쪽 위  → "이 Mac에 관하여"
  · "Apple M..." 이라고 쓰여 있으면 → arm64
  · "Intel..." 이라고 쓰여 있으면 → x64

--------------------------------------------------------
■ 가장 쉬운 설치 (권장) — 클릭 2번
--------------------------------------------------------
1) 이 3개 파일을 모두 같은 폴더에 둡니다 (예: 다운로드 폴더).
2) "install-mac.command" 를 마우스 오른쪽 버튼으로 클릭 → "열기" 선택.
   (처음 한 번만 "확인되지 않은..." 경고가 뜹니다 → "열기" 버튼을 누르세요.)
3) 검은 터미널 창이 열리고 자동으로 설치가 진행됩니다.
   → "✓ 설치 완료" 가 뜨면 끝. 엔터를 눌러 창을 닫으세요.
4) Launchpad(또는 응용 프로그램 폴더)에서 "Mogam Works" 를 실행합니다.
   → 이때부터는 경고 없이 바로 열립니다.

* 경고는 2번 단계에서 딱 한 번만 나옵니다. 그 이후로는 없습니다.

--------------------------------------------------------
■ 앱 실행 후
--------------------------------------------------------
- 처음 실행하면 "로그인" 버튼만 누르면 됩니다.
- 브라우저가 열리며 회사 SSO 로그인 화면이 나옵니다 → 로그인하면 끝.
- 별도의 설정 입력은 없습니다.

--------------------------------------------------------
■ 혹시 설치 도우미가 안 될 때 (수동 설치)
--------------------------------------------------------
1) 내 Mac에 맞는 .dmg 를 더블클릭 → 열린 창에서
   "Mogam Works" 아이콘을 "Applications" 폴더로 드래그.
2) 응용 프로그램 폴더에서 "Mogam Works" 를 마우스 오른쪽 클릭 → "열기".
   경고창이 뜨면 "열기" 를 누릅니다. (처음 한 번만)
3) 만약 "손상되었기 때문에 열 수 없습니다" 라고 나오면,
   터미널(응용 프로그램 > 유틸리티 > 터미널)을 열고 아래를 붙여넣고 엔터:

     xattr -dr com.apple.quarantine "/Applications/Mogam Works.app"

   그 후 다시 앱을 실행하면 됩니다.
